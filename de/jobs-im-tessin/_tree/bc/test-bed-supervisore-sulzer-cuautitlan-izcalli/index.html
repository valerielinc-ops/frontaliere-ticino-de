Actividades principales Realizar pruebas de comportamiento a bombas nuevas o reparadas utilizando un sistema de adquisición de datos, así como instrumentación e instalación del banco de pruebas para certificar que las bombas cumplen por lo requerido por el cliente y normas aplicables. Analizar los resultados de prueba comparando contra lo requerido por el cliente y las normas aplicables para determinar si las bombas están dentro o fuera de lo especificado.

  • Realizar los certificados de pruebas de comportamiento utilizando hoja de cálculo, así como el sistema PumpJob para su envío a cliente.
  • Registrar cada prueba de comportamiento realizada en banco de pruebas para llevar una estadística.
  • Enviar los certificados de prueba a cliente utilizando el sistema SAP para su aprobación.
  • Escanear y archivar los requerimientos hidráulicos utilizando el sistema SAP para dejar registrado que requerimientos necesita la bomba para operar correctamente. Requisitos: Conocimientos en Hidráulica.
