Vollständige Beschreibung

Wer ist Sonar?

Sonar treibt die Zukunft der agentenzentrierten Softwareentwicklung voran. Als führender Anbieter von KI-Codeüberprüfung und -Verifizierung lösen wir ein kritisches Problem: Wir stellen sicher, dass von KI-unterstützten Entwicklern oder autonomen Agenten generierte Software zuverlässig, sicher und wartbar ist.

Durch die nahtlose Integration mit Claude Code, Codex, Cursor, GitHub Copilot, Gemini und Devin helfen wir über 75 % der Fortune 100 bei der Entwicklung vertrauenswürdiger, zuverlässiger und konformer Software. Bei Kunden, die Sonar verwenden, ist die Wahrscheinlichkeit, dass sie einen Ausfall aufgrund von KI-generiertem Code melden, um 44 % geringer.

Wir glauben, dass die Codeüberprüfung das entscheidende fehlende Glied im Agent-Centric Development Cycle (AC/DC) ist. Branchenriesen wie Nvidia, ServiceNow, Booking.com, Goldman Sachs, AstraZeneca und Ford Motor Company. vertrauen darauf, dass wir eine unabhängige, erklärbare, konsistente Überprüfung und Steuerung ihres KI-generierten Codes über Produkte wie die folgenden bieten: • SonarQube: Die weltweit führende Plattform zur Überprüfung und Verifizierung von KI-Code. • SonarQube Foundation Agent: Derzeit an der Spitze der Bestenlisten für die Reparatur von Agent-Software. • SonarSweep und Sonar-Kontexterweiterung: Bereitstellung des Kontexts und der Einschränkungen auf Unternehmensniveau, die Agenten benötigen, um wirklich effektiv zu sein.

Unser Team ist an globalen Standorten in Austin, Bochum, Dubai, Genf, London, Singapur, Tokio und Washington D.C. tätig. Wir bewegen uns mit einer Denkweise, die wir CODE nennen: • Wir sind unseren Kunden und unserer Gemeinschaft verpflichtet. • Besessen von Qualität. • Bewusst in unseren Entscheidungen. • Effektiv als ein Team.

Mit einem Umsatz von über 400 Millionen US-Dollar und einem profitablen, rasanten Wachstum bilden wir das Rückgrat der KI-Software-Revolution. Wenn Sie Lust haben, etwas zu bewirken, schnell aufbauen möchten und bereit sind, an der Spitze der KI zu arbeiten, möchten wir von Ihnen hören.

Positionsbeschreibung

Wir bei Sonar glauben, dass die bloße Meldung von Codeproblemen nicht ausreicht. Um die Qualität der Software weltweit wirklich zu verbessern, müssen wir Millionen von Entwicklern die Möglichkeit geben, sie automatisch zu reparieren. Mit über 400.000 Unternehmen, die auf unsere Produkte vertrauen, haben wir einen einzigartigen Einfluss darauf, wie Software entwickelt wird.

Jüngste Durchbrüche in der KI haben die autonome Sanierung zur Realität gemacht, aber eine große Hürde bleibt bestehen: Vertrauen. Generative KI macht Fehler und Unternehmen können nicht automatisieren, was ihnen nicht vertraut. Hier kommen Sie ins Spiel. Als Senior/Stab-Ingenieur entwerfen Sie das Backend für Verified Autonomous Remediation, einen ausgefeilten Agenten-Workflow, der nicht nur Code generiert, sondern ihn mithilfe der Analyse-Engine von Sonar gründlich testet und validiert. Sie werden die schwierigen technischen Probleme angehen, die erforderlich sind, um die „Vertrauenslücke“ zu schließen.

Was Sie tun werden

  • Entwerfen Sie die „Unified Remediation Engine“. Sie entwerfen die Hochdurchsatz-Entscheidungslogik, die unsere Sanierungsbemühungen antreibt. Sie erstellen die Backend-Dienste, die Anfragen intelligent zwischen deterministischen Sofort-QuickFixes, LLM-basierten Reasoning-Fixes und komplexen Agentenabläufen weiterleiten.
  • Erstellen Sie eine robuste Agentenarchitektur. Sie tragen zum Sonar Remediation Agent-Code bei und überführen Forschungskonzepte in einen belastbaren, hochskalierten Produktionsdienst. Sie implementieren selbstheilende Arbeitsabläufe, bei denen der Agent den von ihm erzeugten Code iterativ korrigiert, bis der Build grün ist.
  • Lösen Sie das „Sandboxing“-Problem. Sie entwerfen die sicheren Ausführungsumgebungen, die für die Ausführung von nicht vertrauenswürdigem, KI-generiertem Code erforderlich sind. Sie entwerfen die Isolationsschichten, die es Agenten ermöglichen, Codeverbesserungen zu wiederholen, ohne unsere Infrastruktur zu gefährden.
  • Ingenieur für Zuverlässigkeit und Sicherheit. Sie implementieren wichtige Sicherheitsmechanismen wie Leistungsschalter, um Anfragen automatisch an die richtige Engine umzuleiten, wenn die Akzeptanzraten sinken. Entscheidend ist, dass Sie den Kosten-Leistungs-Kompromiss tragen und sicherstellen, dass unsere AWS-Architektur auf Millionen von Ereignissen skaliert werden kann, ohne dass die Token-Kosten in die Höhe schnellen.
  • Als technischer „Kraftmultiplikator“ fungieren. Über den Aufbau von Systemen hinaus betreuen Sie das Team durch Designprüfungen und arbeiten mit dem Forschungsteam zusammen, um sicherzustellen, dass unser Agent nicht nur auf dem neuesten Stand der Technik, sondern auch produktionssicher ist.

Erfahrung und Qualifikationen

  • Starke Backend- und Cloud-Expertise. Sie verfügen über mehr als 8 Jahre Erfahrung im Aufbau skalierbarer, resilienter Systeme. Sie verfügen über fundierte Kenntnisse in der AWS-Architektur und wissen, wie man unter Berücksichtigung der Kosten eine hohe Verfügbarkeit und niedrige Latenz gewährleistet.
  • Polyglottes Ökosystem (Java und Python). Sie arbeiten problemlos in einer Hybridumgebung: Java für eine tiefe Integration mit der Core Sonar-Analyse-Engine und Python für die AI/Agent-Argumentationsschicht. Sie sollten in dem einen stark und in dem anderen fähig sein. Wir nutzen verschiedene LLM-Tools und suchen Menschen, die keine Angst vor verschiedenen Sprachen haben.
  • Systemdenken. Sie verstehen, dass „KI“ in der Produktion hauptsächlich „Systems Engineering“ ist. Sie wissen, wie Sie mit asynchronen ereignisgesteuerten Architekturen umgehen, Warteschlangen verwalten und Sandbox-Ausführungsumgebungen entwerfen, um nicht vertrauenswürdigen Code sicher auszuführen.
  • KI- und LLM-Integration. Sie verfügen über praktische Erfahrung in der Entwicklung von Anwendungen, die LLMs orchestrieren (OpenAI, Anthropic oder gehostete offene Modelle). Sie verstehen die Backend-Komplexität von RAG, die Kontextfensterverwaltung und das Prompt Engineering im großen Maßstab.
  • Datengesteuerte Denkweise. Ihnen liegt das „Warum“ am Herzen. Sie möchten Telemetriepipelines erstellen, die zwischen „Bad UX“ und „Bad Code“ unterscheiden und sich dabei auf die wichtigen Metriken konzentrieren.
