Die Position

Die Gelegenheit

Als Senior Cybersecurity Engineer für Cloud & Edge Defense sind Sie der primäre Architekt und Ingenieur, der für die Sicherheit unserer globalen digitalen Grenzen und Multi-Cloud-Ökosysteme verantwortlich ist. Ihre Mission ist es, unsere "Haustür" zu sichern, indem Sie leistungsstarke Verkehrsinspektionslösungen für AWS, GCP und Azure entwerfen und implementieren, wobei Sie die Palo Alto VM-Serie als zentrale Säule verwenden. Dies ist eine technische "Implementierer" -Rolle, bei der Sie eine Cloud-Netzwerksicherheitsinfrastruktur erstellen, entwerfen, bauen und betreiben.

Ihre Hauptaufgaben umfassen

  • Multi-Cloud-Infrastrukturdesign: Konzipieren und entwickeln Sie eine robuste Cloud-Netzwerkinfrastruktur für AWS, GCP und Azure und nutzen Sie Palo Alto-Instanzen für eine gründliche Verkehrsinspektion.
  • Advanced Palo Alto Engineering: Führen Sie eine erweiterte Konfiguration und Verwaltung von Palo Alto-Lösungen (VM-Serie, Panorama) durch, einschließlich komplexer Upgrades und Migrationen in der Produktion.
  • Cloud-Programmierung & Automatisierung: Nutzen Sie Cloud-Anbieter-Netzwerkinfrastrukturen, um Sicherheitslösungen über automatisierte Pipelines mit Terraform und Python zu konfigurieren und bereitzustellen.
  • Feature Enforcement: Implementieren und verwalten Sie App-ID, User-ID, WildFire, Threat Prevention, SSL Decryption und GlobalProtect, um eine Zero Trust-Haltung durchzusetzen.
  • Operational Excellence: Verwalten Sie Sicherheitsrichtlinien als Code und verbessern Sie Automatisierungsworkflows und plattformübergreifende Orchestrierung, um manuelle Reibungen zu vermeiden.
  • Technische Fachkompetenz: Behebung komplexer Probleme im Zusammenhang mit Cloud-nativem Routing, Load Balancing und Firewall-Inspektion in Multi-Cloud-Umgebungen.

Wer du bist

  • Sie haben einen Bachelor-Abschluss in Informatik, Software Engineering, Informationssicherheit oder einem verwandten technischen Bereich.
  • Sie haben eine nachgewiesene Erfolgsbilanz bei der Implementierung von Netzwerksicherheitskontrollen in mindestens zwei großen Cloud-Anbietern (AWS, Azure oder GCP).
  • Sie verfügen über mehr als 3 Jahre Erfahrung in der Konfiguration und Wartung von Palo Alto Next-Generation Firewalls (NGFW), einschließlich TLS-Inspektion, WildFire und GlobalProtect.
  • Sie haben nachweislich Erfahrung mit Ansible, Terraform oder Python, um die Netzwerksicherheitsinfrastruktur in großem Maßstab zu verwalten.
  • Sie haben ein tiefes Verständnis von Kernprotokollen (BGP, OSPF, DNS, TLS/SSL) und wie sie sich mit der Durchsetzung von Sicherheitsmaßnahmen überschneiden.

Bevorzugt

  • Zertifizierungen von Palo Alto Networks PCNSE, AWS Certified Security oder Azure Security Engineer Associate.
  • Proficiency in Infrastructure as Code (IaC) mit Terraform und GitHub zur Aufrechterhaltung versiongesteuerter Sicherheitskonfigurationen.
  • Starke Skriptkenntnisse in Python oder Go, um benutzerdefinierte API-Integrationen zwischen Sicherheitsplattformen zu erstellen.
  • Erfahrung in stark regulierten Umgebungen wie Pharma, Gesundheitswesen oder Finanzen.
  • Ein Selbststarter mit der Fähigkeit, technische Workstreams vom Konzept bis zur Produktion mit minimaler Aufsicht zu verwalten.
